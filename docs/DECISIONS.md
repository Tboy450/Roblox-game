# Design decisions and proposals

## 2026-10-26 — Hybrid modeling workflow

Use Houdini for procedural architecture, modular fixtures, layout variations and repeated detail. Use Blender for individual prop modeling, cleanup, UVs and baking.

## 2026-10-26 — Standalone simulator and background development

The user clarified that the objective is a simulator in another game engine, developed through source files, scripted asset generation and background builds to avoid repeated computer-use sessions. Roblox is the reference project, not the current delivery target. Stop the Roblox importer and Rojo integration work. Preserve the existing reference, assets and legacy integration code. After proposing Godot and receiving "ok continue," implement the standalone prototype in Godot with the hybrid Houdini/Blender asset pipeline. A future Roblox port is a separate discussion and does not change the current objective.
