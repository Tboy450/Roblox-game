# Design decisions and proposals

## 2026-10-26 — Hybrid modeling workflow

Use Houdini for procedural architecture, modular fixtures, layout variations and repeated detail. Use Blender for individual prop modeling, cleanup, UVs and baking. Use Roblox Studio/Luau/Rojo for assembly and gameplay integration.

## 2026-10-26 — Custom project watermark proposal

The user proposed changing the visible prototype watermark into the project's own watermark. Record custom Cornerfield Market branding/watermark design as a requested art-direction proposal. It has not been implemented. A visual mark and an asset's source/provenance are separate records; changing a mark is not recorded as changing the source or license status.
